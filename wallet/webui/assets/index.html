Welcome

A wallet is a key file. Create a new one, or open one you already have.

Choose a network

The wallet is its own node. It joins the network, finds peers, downloads the chain and works your balance out here, on this computer. Nothing is asked of anybody else's server, and nothing outside this machine is trusted for what you hold.

This package is missing its node program, so the wallet cannot run one. Download the wallet again.

Create a new wallet

There is no way to recover a forgotten passphrase. The key file is encrypted with it and nothing else, and it is never written anywhere.

Open a key file

The passphrase is asked for next. Nothing about the file is trusted until it is decrypted.
