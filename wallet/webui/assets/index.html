Balance

There is no transaction list, here or anywhere. A Zycord node keeps no history — it holds the current state and nothing else — so an interface that showed one would be promising something the network does not have.

Send

A one-shot address is burned by any debit, so it must be emptied in one certificate: anything left under it is unreachable forever (docs/WALLET.md rule 1).

Fee and window

The maximum is a solvency bound and the tip is what a producer is paid. Raising the headroom costs nothing unless the market moves into it; it is only reserved from the balance and refunded in the same block.

Receive

Use the persistent address for anything paid more than once — it can never be burned, so it has no grief surface. Use a one-shot address for a single expected payment; it is burned the first time it is debited, which is what keeps that payment unlinkable to the next one.
